# Settings reference

Generated by `tools/Build-SettingReference.ps1` from the settings pages and the rows of `engine/src` and from `engine/api-endpoints.psd1`; do not edit it. Run the script after changing a row, a page or the endpoint catalog (a test fails while this file is stale).

It has two parts that are never added together: which settings pages and controls are known (UI coverage), and which API endpoints and response fields are known (API coverage). A row of the config appears in both: under its page, and as a field of its endpoint.

## UI coverage

Every page of the organization settings menu, in menu order. Addresses are relative to `https://github.com/organizations/<org>/settings/`.
