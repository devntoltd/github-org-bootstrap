# Security policy

## Reporting a vulnerability

Report a vulnerability privately through the **Security** tab of this repository: *Report a vulnerability* opens a
private advisory that only the maintainers see. Please do not open a public issue for it.

Include what is affected, how to reproduce it and what an attacker could do.

## Supported versions

Only the latest release gets fixes. The tool runs with an organization owner's token, so keep your pinned version
current: the [changelog](CHANGELOG.md) names the releases that fix a vulnerability.
